Introduction to Axes and Figures¶

Matplotlib has two main ways to create plots:

1. a script-like approach
2. an object-oriented approach

We are going to walk through the object oriented approach as it will help you make more complicated plots if you ever need them. Additionally, there are a lot of syntactical similarities between the two approaches, so if you know the OO approach you can easily use the scripting approach if it is more convenient.

In [2]:
fig, ax = plt.subplots()

A couple definitions:

1. "Figure" is the outer container of the visual you are creating. Individual plots go inside. 
2. "Axes" are the individual plots (subplots) that go inside of a figure.

In the example above, plt.subplots() creates both a Figure and Axes (that is empty because we have not added anything to it yet. This is equivalent to calling plt.subplots(1,1) (for 1 row of Axes and 1 column of Axes in the Figure).

If we wanted to, we could create a figure with multiple subplots by doing any of the following:

In [3]:
#2 rows, 1 col
fig, ax = plt.subplots(2,1)
In [4]:
#1 row, 2 cols
fig, ax = plt.subplots(1,2)
In [5]:
#3 rows, 2 cols
fig, ax = plt.subplots(3,2)

If you have multiple Axes in your Figure, you can edit any individual Axes object by accessing the specific element in the "ax" variable, which is actually a numpy array when you have multiple Axes.

Specific Axes (subplots) are accessed by grabbing the corresponding position in the array. The top row of the Figure corresponds to the first row in the Array, the second to the second, etc. Remember: array positions are zero indexed.

Additionally, the way you access elements in a numpy array has more flexibilitiy than in a multidimensional list:

-List way: list_name[row][col]
-Numpy way: array_name[row, col] or list way

Exercise 2 - working with categorical data¶

Download the Game_of_Thrones_Script.csv from Canvas. Create a bar chart showing the number of lines spoken for the 10 characters with the most speaking lines througout the show. Also create a bar chart plotting the number of words spoken (for the 10 characters with the most words spoken) througout the show.

CSV stands for comma separated values - we will talk more about working with these files when we talk about pandas next week

In [16]:
import csv
import matplotlib.pyplot as plt

lines = {}

with open("Game_of_Thrones_Script.csv", encoding="utf-8") as got:
    reader = csv.reader(got)

    next(reader)  # skip the header

    for row in reader:
        name = row[4]

        if name in lines:
            lines[name] += 1
        else:
            lines[name] = 1

top10 = sorted(lines.items(), key=lambda x: x[1], reverse=True)[:10]

names = []
counts = []

for name, count in top10:
    names.append(name)
    counts.append(count)

plt.bar(names, counts)
plt.xticks(rotation=45)
plt.xlabel("Character")
plt.ylabel("Number of Lines")
plt.title("10 Characters With the Most Lines")
plt.show()

Exercise 2b: Counting total words¶

Edit your code above to count total words instead of total number of lines for each character, then create a pie chart to visualize the proportion of total words in the show said by each character. Do this for the top 10 characters, then combine all the other characters into a single "other" category for the visualization.

In [20]:
words = {}

with open("Game_of_Thrones_Script.csv", encoding="utf-8") as got:
    reader = csv.reader(got)
    next(reader)

    for row in reader:
        name = row[4]
        sentence = row[5]

        word_count = len(sentence.split())

        if name in words:
            words[name] += word_count
        else:
            words[name] = word_count

# Sort from most words to least words
sorted_words = sorted(words.items(), key=lambda x: x[1], reverse=True)

# Get top 10
top10 = sorted_words[:10]

names = []
counts = []

for name, count in top10:
    names.append(name)
    counts.append(count)

# Add everyone else together
other = 0

for name, count in sorted_words[10:]:
    other += count

names.append("Other")
counts.append(other)
plt.pie(counts, labels=names, autopct="%1.1f%%")

# Make pie chart
plt.pie(counts, labels=names)
plt.title("Words Spoken in Game of Thrones")
plt.show()

Download apple.txt and gamestop.txt from Canvas

First create 4 total lists: gamestopDate, appleDate, gamestopPrice, applePrice

Use these lists to plot the share price of the 2 companies for the last year, apple in red and gamestop in black. Add a legend, x- and y-axis labels, and a title, then save the figure to your computer.

In [19]:
"""
Opening files within the list constructor results in the contents of that file being stored in a list
with each line of the file being stored as a unique element of the list (as a string)
"""
appleData = list(open('apple.txt'))
gamestopData = list(open('gamestop.txt'))
print(appleData[:5])
print(gamestopData[:5])
appleDate = []
applePrice = []
gamestopDate = []
gamestopPrice = []

# Apple
for line in appleData:
    data = line.split()

    appleDate.append(int(data[0]))
    applePrice.append(float(data[1]))

# Gamestop
for line in gamestopData:
    data = line.split()

    gamestopDate.append(int(data[0]))
    gamestopPrice.append(float(data[1]))

# Plot
plt.plot(appleDate, applePrice, color="red", label="Apple")
plt.plot(gamestopDate, gamestopPrice, color="black", label="Gamestop")

plt.xlabel("Day")
plt.ylabel("Share Price ($)")
plt.title("Apple vs Gamestop Share Price")
plt.legend()

plt.savefig("stocks.png")
plt.show()
